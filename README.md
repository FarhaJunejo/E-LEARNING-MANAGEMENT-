# E-LEARNING-MANAGEMENT-
Name : Farha Junejo
Institute : The Sufi Institute Luari Shareef
Instructor: Chandni Talpur

The E-Learning Management System is a console-based application developed in C++ that simulates a simple online learning platform. It allows three types of users: Students, Teachers, and Admin. The system enables course management, student enrollment, lecture uploading, and record keeping using file handling for permanent storage.
This project demonstrates the use of basic programming concepts such as loops, functions, conditional statements, and file handling.
 Objectives
The main objectives of this project are:
•	To develop a simple learning management system in C++ 
•	To implement user authentication (login/register system) 
•	To manage courses efficiently 
•	To allow students to enroll in courses 
•	To enable teachers to upload courses and lectures 
•	To store all data permanently using files
